Bienvenida al Portafolio

Este sitio web reúne los dibujos y animaciones desarrollados originalmente en Khan Academy, ahora adaptados utilizando estándares web modernos con HTML, CSS y JavaScript.

Fundamentos Teóricos

1. La etiqueta HTML <canvas> y sus contextos 2D

La etiqueta <canvas> es un contenedor gráfico en HTML5 que permite dibujar gráficos sobre la marcha mediante secuencias de comandos (usualmente JavaScript). Para poder dibujar en él, se requiere obtener un contexto de renderizado utilizando el método getContext('2d'). Este contexto proporciona propiedades y funciones para trazar rutas, rectángulos, círculos, texto e imágenes.

2. Fundamentos de la librería p5.js

p5.js es una biblioteca de JavaScript que facilita la programación creativa y visual inspirada en Processing. Simplifica la manipulación del elemento <canvas> ofreciendo funciones intuitivas como setup() (para la configuración inicial) y draw() (que actúa como un bucle continuo para animaciones), además de funciones geométricas predefinidas (rect(), ellipse(), fill(), etc.).
