HTML Canvas y contexto 2D

La tecnología que permite transformar instrucciones de código en dibujos digitales.

🎨

¿Qué es la etiqueta canvas?

La etiqueta <canvas> de HTML proporciona una superficie rectangular en la que JavaScript puede dibujar gráficos, figuras, imágenes, texto y animaciones. Por sí sola, la etiqueta crea el área de dibujo; el código JavaScript permite representar los elementos.

¿Cómo funciona el contexto 2D?

El contexto bidimensional se obtiene mediante canvas.getContext("2d"). Este objeto proporciona métodos para dibujar y modificar elementos en dos dimensiones.

  • fillRect(): dibuja rectángulos rellenos.
  • arc(): dibuja arcos y círculos.
  • moveTo() y lineTo(): construyen líneas.
  • fillStyle: define el color de relleno.
  • clearRect(): limpia una zona del lienzo.

Fundamentos de p5.js ✨

Una biblioteca de JavaScript que facilita la creación de arte digital, animaciones e interacciones.

💜

¿Qué es p5.js?

p5.js es una biblioteca gratuita de JavaScript orientada a la programación creativa. Simplifica la creación de gráficos mediante funciones para dibujar formas, aplicar colores, detectar acciones del usuario y producir animaciones.

Funciones principales

  • setup(): inicializa el programa.
  • draw(): actualiza continuamente la escena.
  • createCanvas(): crea el lienzo de dibujo.
  • background(): establece el fondo.
  • ellipse(): dibuja círculos y elipses.
  • rect(): dibuja rectángulos.
  • fill() y stroke(): configuran rellenos y contornos.

Aplicación en los gráficos

Estas funciones permiten controlar el movimiento de objetos, cambiar colores y crear efectos visuales. La función draw() se ejecuta repetidamente, lo que facilita generar animaciones.
